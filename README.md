# FoodLoop – Surplus Food Management Mobile Application

## System Overview

FoodLoop is an Android mobile application developed as a
3-member academic software development project.

The application facilitates surplus food listings, reservations,
orders and communication between food providers and consumers.

## Main Features

- Role-based Provider and Saver home screens
- Food listing and Add Food
- Restaurant information
- Nearby Restaurants and location-based features
- Food reservations and orders
- Pickup time and order validation
- Pickup code verification and order completion
- Notifications and reminders
- Post-payment order processing
- Location and map display

## Technologies

- Kotlin
- Jetpack Compose
- Supabase
- PostgreSQL
- PostGIS
- Mapbox
- WorkManager
- BroadcastReceiver
- SharedPreferences
- Git / GitHub

## System Architecture

The application follows a layered structure involving:

- Jetpack Compose UI
- ViewModels
- Repositories
- Supabase / PostgreSQL database
- Background workers
- Notification components

## Project Structure

The project is organised into different components for:

- Home and food listing
- Restaurant and location features
- Orders and reservations
- Notifications
- Database and repository operations

## Project Type

3-member academic software development project developed
as part of the Diploma in Computer Science coursework.
